Student Expense Tracker System
Overview
A Java command-line application that helps students manage and track their expenses.

Features
Add expenses
Delete expenses
View expenses
Generate spending reports
Save records to file
Input validation
Technologies Used
Java
OOP Concepts
ArrayList
Exception Handling
File I/O
Installation
Clone repository
git clone <https://github.com/atraiu2007/Student-expense-tracker>
Open project in IntelliJ IDEA

Compile:

javac *.java
Run:
java Main
